# Заявки з сайту в Telegram

## Схема

```
Клієнт заповнює форму на сайті (ім'я, телефон*, що зробити, фото)
        │  POST /api/lead
        ▼
functions/api/lead.js (Cloudflare Pages Functions)   ← токен бота тут, у секретах
        │  Telegram Bot API: sendMessage / sendPhoto
        ▼
Telegram-бот надсилає повідомлення власнику (або в групу майстрів)
```

Токен бота **ніколи** не кладеться в код сторінки чи в файли проєкту, лише в
секрети Cloudflare (`TG_BOT_TOKEN`, `TG_CHAT_ID`).

## Що зробити власнику (≈10 хвилин)

1. Відкрити в Telegram **@BotFather** → `/newbot` → назва (наприклад,
   «Заявки Збірка меблів») → нік бота (має закінчуватися на `bot`).
2. BotFather видасть **токен**. Нікому не пересилати і не вставляти в чат з
   Claude; вводиться лише командою `npx wrangler pages secret put TG_BOT_TOKEN`.
3. Написати своєму боту будь-яке повідомлення (`/start`), інакше бот не
   зможе писати вам першим.
4. Дізнатися свій **chat_id** (наприклад, через @userinfobot). Або створити
   групу, додати туди бота і всіх, хто приймає заявки, і взяти chat_id групи
   (починається з `-`).
5. Задати `TG_CHAT_ID` командою `npx wrangler pages secret put TG_CHAT_ID`,
   потім `npm run deploy`.

## Як працює форма (`site/main.js`, `functions/api/lead.js`)

- Обов'язковий лише телефон (мінімум 9 цифр); перевіряється і в браузері, і на сервері.
- Приховане поле-пастка `website` відсіює ботів-спамерів.
- Фото до 5 МБ надсилається разом з текстом (`sendPhoto`), інакше лише текст.
- Після відправки клієнт бачить: «Дякуємо! Заявку отримано…». Якщо щось
  зламалося — «Не вдалося надіслати. Подзвоніть…» з телефоном.
- Якщо секрети Telegram не задані, сервер відповідає 503 і клієнт бачить
  повідомлення з телефоном.

## Формат повідомлення

```
🛠 Нова заявка з сайту
Ім'я: Олена
Телефон: +380 67 123 45 67
Що зробити: зібрати шафу-купе 2 м
Час: 06.10.2026, 14:32:00
```

## Якщо почнеться спам

Додати Cloudflare Turnstile (безкоштовна невидима перевірка «я не робот»).

## На майбутнє: бот з діалогом

Якщо заявок стане багато, бот може сам розпитувати клієнта: тип меблів → фото
→ адреса → зручний час. Можна використати того самого бота.

## Персональні дані

Під формою є рядок про згоду на зв'язок. Заявки ніде, крім Telegram, не
зберігаються.
