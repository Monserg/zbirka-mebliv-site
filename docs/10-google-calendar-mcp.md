# MCP-сервер «Календар майстра» (Google Calendar для ШІ)

Сайт має вбудований MCP-сервер (`/mcp`), через який ШІ-асистент (Claude у
claude.ai, Claude Code, Claude Desktop чи інший MCP-клієнт) може дивитися
календар власника в Google і робити в ньому записи: «запиши Олену на збірку
кухні у вівторок о 15:00», «коли в мене вільно цього тижня на 2 години?».

MCP (Model Context Protocol) — стандартний спосіб дати ШІ набір інструментів.
Наш сервер працює в тому ж проєкті Cloudflare Pages, що й сайт (окремого
хостингу не потрібно), і сам ШІ-моделей не викликає: він лише виконує
команди, які надсилає підключений асистент.

## Що вміє

| Інструмент | Що робить |
|---|---|
| `list_events` | список подій за період (за замовчуванням — найближчі 7 днів), з id |
| `free_slots` | вільні проміжки в робочі години (за замовчуванням 09:00–18:00) під роботу заданої тривалості |
| `create_event` | створити подію: назва, початок, кінець або тривалість, адреса, опис |
| `update_event` | змінити назву, час, адресу чи опис події за id |
| `delete_event` | видалити подію за id |

Усі часи — київські. Асистент отримує інструкцію: перед записом перевірити
зайнятість і переконатися, що власник справді цього хоче.

Чого **не** вміє: запрошувати учасників на подію (Google не дозволяє це
сервісному акаунту без корпоративного домену) і працювати з іншими календарями,
крім того, яким поділився власник.

## Як це влаштовано

```
Claude (claude.ai / Claude Code / Desktop)
   │  MCP (JSON-RPC через HTTPS) + секретний токен
   ▼
https://<сайт>/mcp/<MCP_TOKEN>        functions/mcp/[[path]].js → lib/mcp-calendar.js
   │  Google Calendar API, доступ від імені сервісного акаунта (lib/gcal.js)
   ▼
Календар власника в Google (поділений із сервісним акаунтом)
```

- **Сервісний акаунт Google** — «технічний користувач» без пароля, з ключем.
  Власник ділиться своїм календарем із цим акаунтом з правом «Вносити зміни
  до подій». Ніякого входу через Google-пароль власника не потрібно, доступ
  можна будь-коли забрати, прибравши акаунт зі списку доступу до календаря.
- **Секретний токен `MCP_TOKEN`** захищає сам MCP-сервер: без нього будь-хто
  міг би писати в календар. Токен передається або в заголовку
  `Authorization: Bearer …`, або в адресі `/mcp/<токен>` (для claude.ai, де
  заголовки задати не можна). Щоб відкликати доступ — змінити секрет.
- Access-токен Google кешується в KV (`gcal:token`) на ~55 хвилин.

## Налаштування (один раз, ~20 хвилин)

### Крок 1. Сервісний акаунт у Google Cloud

Робить розробник або власник (під будь-яким Google-акаунтом; це не обов'язково
має бути акаунт власника календаря).

1. Відкрити https://console.cloud.google.com, створити проєкт (наприклад
   `zbirka-mebliv`). Платіжна картка не потрібна — Calendar API безкоштовний.
2. **APIs & Services → Library** → знайти **Google Calendar API** → **Enable**.
3. **APIs & Services → Credentials → Create credentials → Service account**.
   Назва, наприклад, `calendar-bot`. Ролі можна не давати. **Done**.
4. Відкрити створений акаунт → вкладка **Keys → Add key → Create new key →
   JSON**. Завантажиться файл `*.json` — це ключ, він секретний. Запам'ятати
   адресу акаунта виду `calendar-bot@zbirka-mebliv.iam.gserviceaccount.com`
   (поле `client_email` у файлі).

### Крок 2. Власник ділиться календарем

У Google Календарі власника (на комп'ютері, https://calendar.google.com):
**Налаштування → Налаштування моїх календарів → (свій календар) → Доступ для
окремих людей чи груп → Додати людей** → вставити адресу сервісного акаунта,
права **«Вносити зміни до подій»** → **Надіслати**.

Id календаря — у тому ж розділі, нижче, **«Інтегрувати календар» →
«Ідентифікатор календаря»**. Для основного календаря це адреса Gmail власника.

### Крок 3. Секрети Cloudflare

У папці проєкту (команди просять ввести значення; для JSON-ключа значення
подається з файлу):

```bash
npm run secret -- GCAL_SERVICE_ACCOUNT < ~/Downloads/zbirka-mebliv-xxxxxx.json
```

```bash
npm run secret -- GCAL_CALENDAR_ID
```

```bash
npm run secret -- MCP_TOKEN
```

`MCP_TOKEN` — довільний випадковий рядок від 16 символів (сервер коротші
відхиляє). Згенерувати можна так:

```bash
openssl rand -hex 24
```

Після цього `npm run deploy`, щоб функції підхопили секрети. JSON-файл ключа
після завантаження в секрети видалити з комп'ютера (або зберігати поза
папкою проєкту; у репозиторій він потрапити не повинен).

### Крок 4. Перевірка

```bash
curl -s https://zbirka-mebliv.pages.dev/mcp -H "Authorization: Bearer <MCP_TOKEN>" -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"list_events","arguments":{}}}'
```

Має повернутися список подій на тиждень (або «подій немає»). Помилка «немає
доступу» означає, що календарем ще не поділилися з сервісним акаунтом;
«не знайдено» — невірний `GCAL_CALENDAR_ID`.

## Підключення до Claude

**claude.ai (сайт і застосунки, потрібен план Pro/Max/Team):** Settings →
Connectors → **Add custom connector** → Name «Календар майстра», URL
`https://<сайт>/mcp/<MCP_TOKEN>` (токен прямо в адресі; поля OAuth лишити
порожніми) → Add. Далі в чаті увімкнути конектор і писати звичайною мовою.

**Claude Code:**

```bash
claude mcp add --transport http kalendar https://zbirka-mebliv.pages.dev/mcp --header "Authorization: Bearer <MCP_TOKEN>"
```

**Claude Desktop** — так само через Settings → Connectors (як у claude.ai).

**Інші MCP-клієнти** (ChatGPT, Cursor тощо): тип транспорту «Streamable
HTTP», адреса `/mcp`, заголовок `Authorization: Bearer <MCP_TOKEN>`, або адреса
`/mcp/<MCP_TOKEN>` без заголовка.

Після зміни домену (`master-mebliv.com.ua`) адресу в конекторі треба оновити.

## Безпека

- Токен в адресі — це як пароль: не публікувати, не надсилати в чати
  стороннім. Якщо витік — `npm run secret -- MCP_TOKEN` з новим значенням,
  `npm run deploy`, оновити адресу в конекторі.
- Сервісний акаунт бачить лише ті календарі, якими з ним поділилися. Пошта,
  контакти, Диск власника йому недоступні.
- Видалення події незворотне (Google-кошик для подій діє 30 днів через
  інтерфейс Google Календаря, але сервер про це не знає). Асистенту дано
  інструкцію підтверджувати видалення.
- Пошуковики на `/mcp` не ходять (`robots.txt`), а без токена сервер відповідає
  401.

## Як протестувати

### Рівень 1. Локально, без Google (протокол і авторизація)

```bash
npm run dev
```

Токен для локального запуску лежить у `.dev.vars` (`MCP_TOKEN`). Список
інструментів:

```bash
curl -s -X POST http://localhost:8788/mcp -H "Authorization: Bearer <MCP_TOKEN з .dev.vars>" -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

Має повернутися JSON із п'ятьма інструментами. Без токена — 401. Виклик
інструмента відповість «Google Calendar не налаштовано» — це очікувано.

Те саме справжнім MCP-клієнтом (офіційний MCP Inspector, токен в адресі):

```bash
npx -y @modelcontextprotocol/inspector --cli http://localhost:8788/mcp/<MCP_TOKEN> --transport http --method tools/list
```

### Рівень 2. Опублікований сайт із живим календарем

Після кроків 1–3 і `npm run deploy`:

```bash
curl -s https://zbirka-mebliv.pages.dev/mcp -H "Authorization: Bearer <MCP_TOKEN>" -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"list_events","arguments":{}}}'
```

Має прийти список подій на тиждень або «подій немає». «Немає доступу» —
календарем ще не поділилися з сервісним акаунтом; «не знайдено» — невірний
`GCAL_CALENDAR_ID`.

Створити тестову подію і перевірити, що вона з'явилася в Google Календарі
власника:

```bash
curl -s https://zbirka-mebliv.pages.dev/mcp -H "Authorization: Bearer <MCP_TOKEN>" -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"create_event","arguments":{"title":"Тест — видалити","start":"2026-10-15T15:00"}}}'
```

У відповіді буде id події; видалити її можна інструментом `delete_event` або
вручну в календарі.

### Рівень 3. Через Claude

Локально з Google (без деплою): додати в `.dev.vars` рядки
`GCAL_CALENDAR_ID=...` і `GCAL_SERVICE_ACCOUNT=<JSON ключа в один рядок>`
(файл у `.gitignore`), перезапустити `npm run dev` і підключити сервер до
Claude Code:

```bash
claude mcp add --transport http kalendar http://localhost:8788/mcp --header "Authorization: Bearer <MCP_TOKEN>"
```

Потім у Claude Code: «що в мене в календарі цього тижня?», «коли вільно на
2 години?», «запиши Олену на збірку шафи у четвер о 15:00». Для claude.ai
потрібна вже опублікована адреса (розділ «Підключення до Claude»).

Автоматичні тести коду (підпис JWT, перехід на зимовий час, усі інструменти з
підробленим Google API) виконано 2026-10-09 у Node; окремого тестового
скрипта в репозиторії немає.
