# CLAUDE.md

Сайт «Збірка та ремонт меблів — Хмельницький»: односторінковий сайт + адмінка
+ заявки в Telegram на Cloudflare.

## Продовження роботи

Історії чату немає: усе, що вирішили і зробили, записано у файлах.
Почати з `README.md` (повний опис і стан), потім `TODO.md` (наступні кроки).
Рішення та їх причини — `docs/01-decisions.md`, технічні деталі —
`docs/08-technical.md`.

## Ключове

- Сайт у `site/` (чистий HTML/CSS/JS, без фреймворків), дизайн — варіант 1
  «Теплий майстер».
- Cloudflare Pages + Pages Functions (`functions/`) + KV (`CONTENT`).
- Адмінка `/admin`: прайс, фото, зміна пароля; вхід за логіном і паролем.
- Заявки: форма → `/api/lead` → Telegram Bot API.
- Локально: `npm run dev` → http://localhost:8788 (тестовий логін/пароль у `.dev.vars`).
- Демо для клієнта: `python3 scripts/build-demo.py` → `dist/zbirka-mebliv-demo.html`.
- Матеріали старого сайту на Wix — `reference/old-wix-site/` (лише довідка).

## Правила

- Спілкування і тексти сайту — українською.
- Токени і паролі ніколи не класти в код чи репозиторій, лише в секрети
  Cloudflare (`wrangler pages secret put`). `.dev.vars` — тільки тестові значення.
- Нові рішення дописувати в `docs/01-decisions.md` з датою; виконані пункти
  позначати в `TODO.md`.
- Після змін у `site/` перезібрати демо, якщо його треба віддати клієнту.
