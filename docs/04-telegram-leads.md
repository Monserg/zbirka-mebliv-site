Оновлено 2026-10-08. Дві різні задачі, два різні механізми:

| Задача | Кнопка на сайті | Через що працює | Стан |
|---|---|---|---|
| 1. Отримання заявок | «Надіслати заявку» (форма) | **Telegram-бот** → повідомлення власнику | код готовий, бот створений, секрети не задані |
| 2. Переписка з клієнтом | «Написати у Telegram» | **особистий Telegram власника** (посилання `t.me/+380969758615`), бот не потрібен | вписано 2026-10-08 |

Бот потрібен лише для заявок: він вміє надсилати повідомлення, але не вміє
«розмовляти» замість власника. Переписка йде напряму з акаунтом власника,
так клієнт одразу бачить живу людину, а власник відповідає зі свого телефону.

## Частина 1. Заявки з форми в Telegram

### Схема

```
Клієнт заповнює форму: Ім'я*, Телефон*, Що зробити*, Фото (необов'язково)
        │  натискає «Надіслати заявку»
        │  браузер перевіряє, що поля зі * заповнені (site/main.js)
        │  POST /api/lead
        ▼
functions/api/lead.js (Cloudflare Pages Functions)   ← токен бота тільки тут, у секретах
        │  повторна перевірка полів зі *
        │  Telegram Bot API: sendMessage / sendPhoto
        ▼
Бот надсилає повідомлення власнику (або в групу майстрів)
```

### Крок 1. Обов'язкові поля (Claude, у коді)

Зараз обов'язковий лише телефон. Зробити обов'язковими три поля і позначити
їх зірочкою:

- [ ] `site/index.html`: підписи «Ім'я *», «Телефон *», «Що зробити *»;
      атрибут `required` на `name`, `phone`, `task`; під кожним полем рядок
      помилки `.err` («Вкажіть ім'я», «Вкажіть телефон, щоб ми могли
      передзвонити», «Опишіть, що потрібно зробити»). Під формою підпис
      «\* — обов'язкові поля».
- [ ] `site/main.js`: при натисканні «Надіслати заявку» перевірити всі три
      поля (ім'я не порожнє, телефон має ≥ 9 цифр, опис не порожній).
      Підсвітити **всі** незаповнені поля одразу, поставити курсор у перше з
      них, запит на сервер не відправляти. Помилка зникає, щойно поле
      почали заповнювати.
- [ ] `site/styles.css`: стиль для поля з помилкою (червона рамка через
      `--bad`), щоб було видно не лише текст під полем.
- [ ] `functions/api/lead.js`: сервер теж відхиляє заявку без імені, телефону
      чи опису (відповідь 400), щоб перевірку не можна було обійти.
- [ ] Перевірити локально (`npm run dev`): порожня форма → три помилки;
      заповнена → запит на `/api/lead` (без секретів відповість 503, це
      нормально).
- [ ] Перезібрати демо: `python3 scripts/build-demo.py`.

### Крок 3. Дізнатися chat_id (власник, ≈2 хвилини)

Куди приходитимуть заявки — на вибір:

- **Особисто власнику.** Відкрити **@userinfobot**, натиснути Start, він
  покаже `Id` (число). Це і є `TG_CHAT_ID`.
- **У групу** (якщо заявки приймають кілька людей). Створити групу, додати
  в неї бота і всіх, хто приймає заявки. Додати в групу @userinfobot чи
  надіслати в ній команду боту; chat_id групи починається з `-`
  (наприклад `-1001234567890`). Після цього @userinfobot з групи видалити.

Рекомендація: почати з особистого чату, групу зробити пізніше за потреби.

Альтернатива без @userinfobot: після того як власник натиснув Start у боті,
розробник виконує в терміналі (підставивши токен; команду в чат не копіювати):

```bash
curl -s "https://api.telegram.org/bot<ТОКЕН>/getUpdates"
```

У відповіді `"chat":{"id":123456789,...}` — це і є `TG_CHAT_ID`. Якщо
відповідь порожня (`"result":[]`), власник ще не натиснув Start.

### Крок 4. Задати секрети на Cloudflare (власник разом із Claude)

Виконується після публікації сайту на Cloudflare Pages
(`docs/08-technical.md` → «Публікація»). Токен і chat_id вводяться
в терміналі, у репозиторій не потрапляють:

```bash
npm run secret -- TG_BOT_TOKEN
```

```bash
npm run secret -- TG_CHAT_ID
```

Або в панелі Cloudflare: Pages → проєкт → Settings → Environment variables
→ додати обидві змінні як **Secret** для Production.

- [ ] Задати `TG_BOT_TOKEN`
- [ ] Задати `TG_CHAT_ID`
- [ ] Передеплоїти: `npm run deploy` (секрети підхоплюються новим деплоєм)

Для локальної перевірки можна додати ті самі змінні в `.dev.vars`
(файл не в репозиторії), але тоді тестові заявки підуть у справжній Telegram.

- [ ] У Telegram має прийти повідомлення:


- [ ] Відправити заявку без фото — має прийти текстом.
- [ ] Спробувати відправити порожню форму — сайт має показати помилки і
      нічого не надсилати.
- [ ] Увімкнути сповіщення для чату з ботом на телефоні, щоб не пропустити
      заявку.

### Що вже працює в коді (`functions/api/lead.js`)

- Приховане поле-пастка `website` відсіює ботів-спамерів.
- Фото до 5 МБ надсилається разом з текстом (`sendPhoto`), інакше лише текст.
- Якщо секрети не задані, сервер відповідає 503, клієнт бачить «Не вдалося
  надіслати. Подзвоніть…» з телефоном.
- Заявки ніде, крім Telegram, не зберігаються.

Якщо почнеться спам — додати Cloudflare Turnstile (безкоштовна невидима
перевірка «я не робот»).

## Частина 2. Кнопка «Написати у Telegram» (переписка)

### Як працює

Кнопка — звичайне посилання на Telegram власника. Клієнт натискає, у нього
відкривається Telegram з чатом з Артемом, далі переписка як з будь-якою
людиною. Бот тут не бере участі, нічого налаштовувати на сервері не треба.

### Крок 1. Обрати, куди вести посилання (власник)

Варіанти, від простого до складного:

1. **Нік власника** (рекомендовано). Посилання `https://t.me/нік`.
   Потрібен нік у Telegram: Налаштування → Ім'я користувача. Якщо ніку
   немає, створити його (наприклад `artem_mebli_km`).
2. **Номер телефону**. Посилання `https://t.me/+380969758615`. Працює
   лише якщо в Telegram власника дозволено знаходити його за номером
   (Налаштування → Конфіденційність → Номер телефону → «Хто може знайти
   мене за номером»: Усі). Нік не потрібен, але налаштування
   приватності доведеться відкрити.
3. **Окремий робочий акаунт** на другу SIM, якщо не хочеться світити
   особистий. Той самий варіант 1, але з ніком робочого акаунта.

Переписка через бота (клієнт пише боту, бот пересилає власнику, власник
відповідає через бота) можлива, але складніша і для клієнта виглядає
гірше. Залишено в TODO як «пізніше».

- [x] Обрано варіант 2 — за номером телефону, ніку немає (2026-10-08).
      Власнику треба перевірити налаштування приватності (див. вище).

### Крок 2. Вписати на сайт (Claude)

- [x] `site/index.html`: `https://t.me/+380969758615` у двох місцях:
      посилання «Написати у Telegram» у блоці «Залишити заявку» та кнопка
      «Telegram» у нижній панелі на телефоні (2026-10-08).
- [x] Перезібрано демо (2026-10-08).

Напис кнопки — саме «Написати у Telegram» (виправлено 2026-10-08).

стоїть «Подзвонити» і довгий текст не вміщається на ширині 360 px.

## Порядок виконання (коротко)

1. Claude: обов'язкові поля зі зірочкою у формі (Частина 1, крок 1).
2. Власник: створити бота, натиснути Start, дізнатися chat_id (кроки 2–3).
3. Власник: повідомити Telegram-нік для переписки (Частина 2, крок 1).
4. Claude: вписати нік на сайт, перезібрати демо (Частина 2, крок 2).
5. Публікація на Cloudflare (`docs/08-technical.md`).
6. Власник з Claude: задати секрети `TG_BOT_TOKEN`, `TG_CHAT_ID`, передеплоїти.
7. Власник: тестова заявка і тестове повідомлення (кроки «Перевірити»).

## На майбутнє: бот з діалогом

Якщо заявок стане багато, той самий бот може сам розпитувати клієнта:
тип меблів → фото → адреса → зручний час. Потрібен webhook
(`functions/api/telegram.js`) і збереження стану діалогу в KV.

## Персональні дані

Під формою є рядок про згоду на зв'язок. Заявки ніде, крім Telegram, не
зберігаються.
