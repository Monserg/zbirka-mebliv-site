## Важливо для перенесення на інший хостинг

Wix не дозволяє експортувати сайт для запуску на іншому хостингу. Ця копія —
статичний «зліпок» відрендерених сторінок. Він відкривається локально і може
бути завантажений на будь-який статичний хостинг, але:

1. **Форма «Напишіть нам»** на сторінці Контакти відправляє дані на сервери Wix і
   на іншому хостингу працювати не буде. Треба замінити на свою форму або
   посилання `mailto:`.
2. Частина JS-скриптів Wix (`assets/static.parastorage.com/...`) звертається до
   Wix API; без інтернету або після видалення сайту на Wix можливі помилки
   в консолі, але контент і верстка відображаються (перевірено локально).
3. Сторінки «Послуги», «О компании», «Отзывы» містять шаблонний текст Wix
   («Это текст. Нажмите здесь...») — його ніколи не заповнювали.

Рекомендація: використати `content.txt` і `images-original/` як матеріал, щоб
зібрати сайт заново на новому хостингу (простий HTML або будь-який конструктор).
