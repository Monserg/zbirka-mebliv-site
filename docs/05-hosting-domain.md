# Хостинг і домен

Ціни орієнтовні на 2026-10-06. Перед покупкою перевіряти на сайті реєстратора,
**особливо ціну продовження** (не тільки першого року).

## Хостинг: Cloudflare Pages

- Безкоштовно, трафік без обмежень, SSL (https) автоматично.
- Серверна частина (форма заявок, адмінка) — Pages Functions, безкоштовно
  до 100 000 запитів на добу.
- Сховище прайсу, фото і пароля — Cloudflare KV, безкоштовно: 1 ГБ,
  100 000 читань і 1 000 записів на добу. **Платіжна картка не потрібна.**
- Без домену сайт доступний за адресою на кшталт `zbirka-mebliv.pages.dev`.
- Публікація: `npm run deploy` з папки проєкту (покроково — у
  [08-technical.md](08-technical.md)).

Потрібен акаунт Cloudflare (безкоштовний). Реєструє власник сам.

## Домен

| Варіант | Приклад | Ціна/рік |
|---|---|---|
| Без домену | `zbirka-mebliv-khm.pages.dev` | 0 грн |
| `.in.ua` / `.km.ua` (міський домен Хмельницького) | `zbirka-mebliv.km.ua` | ~100–250 грн |
| **`.com.ua`** (рекомендовано) | `zbirka-mebliv.com.ua` | ~150–300 грн |
| `.com` | `zbirkamebliv.com` | ~450–600 грн |

Реєстратори: NIC.ua, Imena.ua, Hostiq.ua тощо.

- `zbirka-mebliv.com.ua`

- `majster-mebliv.km.ua`

Порада: коротко, легко продиктувати по телефону, без цифр.

### Підключення домену до Cloudflare Pages

1. Купити домен у реєстратора.
2. У Cloudflare додати домен (безкоштовний план) і отримати 2 NS-сервери.
3. У панелі реєстратора замінити NS-сервери на ті, що дав Cloudflare.
4. У Cloudflare Pages → Custom domains → додати домен. SSL видається
   автоматично.

## Чого не купувати

- Хостинг з «доменом у подарунок»: хостинг не потрібен.
- Конструктори (Wix Premium, Tilda тощо, ~2 000–6 000 грн/рік).
- Домен з великою знижкою на перший рік і дорогим продовженням.
